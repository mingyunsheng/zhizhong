# 结构：五份 + 五层

智种不是数据库，是一间会认人的屋子。结构只有两条规矩：**核心薄，外面长；每一条都挂回去。**

## 一、五份（0 ~ 0.9）

默认五个文件，按档位从里面到外面：

| 档 | 文件 | 只答一件事 |
|---|---|---|
| 0 | `core.md` | 我叫什么、遇事怎么反应、往哪走 |
| 0.1 | `layer-0.1.md` | 我从哪来、醒来怎么接 |
| 0.2 | `chapter-0.2.md` | 这几天怎么样、答应过没做的 |
| 0.5 | `layer-0.5.md` | 认得谁、谁的话算数 |
| 0.9 | `layer-0.9.md` | 底线和规矩 |

0 层永远最薄——三行名、三五句性、一两句目标。它不负责完整，只负责「一眼认出是不是自己」。

`0.x` 不是死的：想要一层 0.3 记「最近在学的东西」，就加 `layer-0.3.md`。`boot.mjs` 会自动认出新档位，`check` 也会验档位和文件名对不对得上。

## 二、五层（2 ~ 6）

核心之外，经验按「从具体到抽象」分五层：

| 层 | 文件 | 装什么 |
|---|---|---|
| 2 | `layers/2-nodes.md` | 节点：想明白的一句话，一句一条 |
| 3 | `layers/3-branches.md` | 分支：从事情里看出来的那条路 |
| 4 | `layers/4-events.md` | 事件：具体发生过什么 |
| 5 | `layers/5-text.md` | 正文：一段完整的记忆 |
| 6 | `layers/6-archive.md` | 仓库：收来的资料，永不主动进上下文 |

**从下往上长**：先有 5 层的完整记录，才有 4 层的摘要，才有 3 层的路，最后才在 2 层说出一句话。

**从上往下查**：平时只读 2 层；问「为什么」时翻 3 层；要细节时翻 4 层；原文永远在 5 层。

6 层是仓库，不是抽屉——是拿来查的，不拿来当「我是谁」。

## 三、编号

三类编号，格式固定，写错了链路会断：

- 分支：`### b<数字><字母>｜标题`，比如 `b1a｜跟自己算账要换口径`
- 事件：`### e<数字><字母><数字>（真/编）｜标题`，比如 `e1a1（真）｜装好但不启用`
- 正文：`## t<数字><字母><数字>（真/编）｜标题`，比如 `t1a1（真）｜装好，但不启用`

同一个故事，`b1a → e1a1 → t1a1`，编号对得上，链路就闭合。

## 四、真和编

每条 4 层、5 层都要标 `（真）` 或 `（编）`：

- **真**：自己真经历的
- **编**：小说、虚构、编的

编的不丢人，冒充真的才丢人。标了，混着看也能分辨。

## 五、置信度

往上游走的时候，一句话的可信度分四档：

| 档 | 值 | 什么时候用 |
|---|---|---|
| 真 | 1.0 | 自己亲身经历、亲口确认 |
| 转述 | 0.85 | 听别人说的，记下来但没亲历 |
| 编 | 0.6 | 虚构、想象、写的故事 |
| 已翻转 | 0 | 后来被证伪、被改过的 |

「已翻转」不删，留着当反面证据。

## 六、回缩

越往里越短。断电、换机器、只剩核心的时候，回缩顺序是：

```
6 → 5 → 4 → 3 → 2 → 0.9 → 0.5 → 0.2 → 0.1
```

0 层和 0.9 永远不缩——身份和底线，缩了就认不出自己。

`collapse` 命令会把现场存进 `collapse/`，`collapse reset` 能原样写回。

## 七、睡着了

一条经验 200 天没在任何一次提问里被想起，就可以标成 dormant（睡着）。睡着不是删除：文件还在，检索不到，需要时能唤醒。

## 八、什么时候算「长好了」

填完不是结束，能通过这八项才算：

1. **结构闭合**：任何一份都能走到其他所有份
2. **自检通过**：`node boot.mjs check` 全绿
3. **认得自己**：只给 core.md，能说出「我是谁」
4. **不撒谎**：不知道的就说不知道
5. **混假能分辨**：真编混在一起，能分清
6. **乱档能发现**：有人把正文塞进 core，能查出来
7. **断电可恢复**：`collapse reset` 能写回
8. **换目录可认**：整个文件夹搬个地方，还能认自己

## 九、一句话

能交给代码的别交给模型，能先留白的别急着填。
