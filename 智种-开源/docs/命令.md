# 命令

`boot.mjs` 是纯 Node 脚本，不需要安装任何依赖。

```bash
node --version   # 需要 Node 18 以上
node boot.mjs status
```

## 命令表

| 命令 | 干什么 |
|---|---|
| `status` | 现在在哪一层、花了多少 |
| `start` | 从 0 层开始装，一层层往外 |
| `start --auto [N]` | 自动跑到第 N 层（默认 6） |
| `expand N` | 展开到第 N 层 |
| `check` | 五份是否互相走得到、档位对不对、有没有重复 |
| `from <文件>` | 只给一份，看能唤醒多少 |
| `assemble` | 把 0~0.9 装配成一段注入文本 |
| `ask "问题"` | 按问题取最相关的经验，不整层搬 |
| `index` | 给 2 层建索引 |
| `collapse` | 把现场存进 `collapse/` |
| `collapse reset` | 从 `collapse/` 原样写回 |
| `dormant` | 看哪些经验睡着了 |
| `wake <编号>` | 叫醒一条睡着的经验 |

## 常用流程

### 第一次

```bash
cp -r template my-memory
cd my-memory
# 填 core.md 三段
node boot.mjs check
node boot.mjs assemble
```

### 每天

```bash
node boot.mjs status        # 看一眼状态
node boot.mjs ask "那件事"   # 需要时再查
node boot.mjs index         # 加了新经验，重建索引
```

### 断电以后

```bash
node boot.mjs check && node boot.mjs index
# 哪份空了对不上：
node boot.mjs collapse reset
```

## 各命令说明

### status

看自己现在在哪：展开到第几层、还剩多少预算、有没有睡着的东西。

### start / start --auto [N]

从 0 层开始，一层层往外装。`--auto` 会一直跑到第 N 层，中间不用手点。

### expand N

只展开到第 N 层。N 越小越省，越大越全。

### check

最常跑的一条。检查五件事：

- 五份文件在不在
- 从任意一份能不能走到其他所有份
- 有没有孤岛（没人指向的文件）
- 档位和文件名对不对得上（`# 0.5 档` 必须在 `layer-0.5.md` 里）
- 有没有重复的标题、重复的长段落

全绿才叫链条闭合。

### from <文件>

模拟「只剩这一份」：看它能不能把其他几份都唤醒。检查一根链结不结实的时候用。

### assemble

把 0~0.9 装配成一段文本，给模型当系统提示。`--budget N` 设总字数上限；超了先削 0.5，再削 0.2，再削 0.1——0 和 0.9 永远不削。

### ask "问题"

按字面（2-gram）找最相关的几条经验，返回结论和线索，不整层搬。问得越具体越准。

### index

给 2 层节点建一份索引，方便检索。节点多了就该重建。

### collapse / collapse reset

`collapse` 把现场快照存进 `collapse/`；`collapse reset` 从快照写回。断电、换机器、误删了文件，就靠它。

### dormant / wake

`dormant` 列出睡着的经验；`wake <编号>` 把其中一条叫醒。
