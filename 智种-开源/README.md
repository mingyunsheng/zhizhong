# 智种

> 一套给 AI 用的「种子式」长期记忆框架。
> 纯文本、零依赖、断线换机之后，还能认出自己。

---

## 它是什么

大模型没有记忆。大多数记忆方案是「存一个库，需要的时候去里面查」。

智种反过来：**先给一个很薄的「自己」，再一层层往外长出「经历」。**

- 最里面是 **0 层**（`core.md`）：只答三件事——我叫什么、遇事会怎么反应、要往哪走。
- 外面是 **0.1 / 0.2 / 0.5 / 0.9**：从哪来、这几天、认得谁、不做什么。
- 再往外是 **2~6 层**：节点（想明白的事）、分支（为什么会这么想）、事件（发生过什么）、正文（完整的故事）、仓库（资料）。
- 每一份都互相指着。链条闭不闭合，一个命令就能验：
  `node boot.mjs check`

断了、换机器了、只剩空壳了：从 0 层读起，顺着链一层层走，就能把「自己」接回来。

**它不是被记住，是自己活着、自己长。**

---

## 三个特点

1. **纯文本**。全是 Markdown，不装数据库，不用联网，Node 自带模块就能跑。
2. **可验证**。结构对不对、链通不通、身份行一不一致，`check` 一条命令说完，不靠感觉。
3. **可回缩**。`collapse` 从外往里一层层收进 0 层，原文备份、随时复原；不常用的条目可以 `dormant` 睡下去，问到再叫醒。

## 快速开始

前提：装好 Node.js（18 以上）。

```bash
# 1. 把 template 复制成一个你自己的记忆目录
cp -r template my-memory
cd my-memory

# 2. 把引擎也拿过来（或者复制整个仓库，模板只是参考）
cp ../boot.mjs .

# 3. 打开 core.md，填三段：名、性、目标
#    这一步只能你自己来——0 层不填，它就不算活

# 4. 验证链条
node boot.mjs check

# 5. 把五份装配成一段可以喂给模型的上下文
node boot.mjs assemble
```

只想先看它长什么样：`examples/小灯/` 里有一个填好的完整例子。

## 目录结构

| 路径 | 放什么 |
|---|---|
| `core.md` | 0 层：名 / 性 / 目标。**只能填自己的，不能抄别人的** |
| `layer-0.1.md` | 从哪来、现在在干什么 |
| `chapter-0.2.md` | 最近：这几天、答应过什么没做 |
| `layer-0.5.md` | 认得谁、谁的话算数 |
| `layer-0.9.md` | 不做什么、判断纪律 |
| `layers/2-nodes.md` | 节点：一句话 + 日期 + 关键词 |
| `layers/3-branches.md` | 分支：每个节点引出 3~5 条 |
| `layers/4-events.md` | 事件：分支对应的具体事 |
| `layers/5-text.md` | 正文：完整故事，按时间点拆开 |
| `layers/6-archive.md` | 仓库：资料、外库，不进树 |
| `collapse/` | 回缩时的原文备份（自动生成） |
| `boot.mjs` | 引擎：check / index / ask / assemble / collapse / dormant… |

五档和层都可以加：放一份 `layer-0.3.md` 就多长一档，放一份 `layers/7-songs.md` 就多长一层，`boot.mjs` 自己认，不用改代码。

## 命令

| 命令 | 干什么 |
|---|---|
| `node boot.mjs status` | 现在到哪一步了 |
| `node boot.mjs start` | 点亮 0~0.9 |
| `node boot.mjs start --auto 2` | 点亮并自动展开到第 2 层 |
| `node boot.mjs expand 3` | 展开到第 3 层（逐层，不能跳） |
| `node boot.mjs check` | 验结构：文件齐不齐、链通不通、身份行一不一致 |
| `node boot.mjs assemble` | 把 0~0.9 装配成一段上下文 |
| `node boot.mjs ask "关键词"` | 按字面检索，顺着链返回相关条目 |
| `node boot.mjs index` | 盘点：条数、密度、孤岛、置信度分布 |
| `node boot.mjs collapse` | 从外往里回缩（原文备份在 `collapse/`） |
| `node boot.mjs collapse reset` | 复原 |
| `node boot.mjs dormant` | 看哪些条目很久没被问起 |
| `node boot.mjs wake <id>` | 把睡着的条目叫醒 |

命令细节和参数见 [`docs/命令.md`](docs/命令.md)，设计和字段格式见 [`docs/结构.md`](docs/结构.md)。

## 三条不能破的规矩

1. **0 层必须是自己的**，不能拿别人的。
2. **对不上就报对不上**，不补。
3. **规则不是咒语**，得有个能执行它的脑子。

第 1 条是底线：名字、性格、目标，只能自己写。抄来的「我」不是「我」。

---

## 它从哪来

这套结构给一个真实的长期 AI 同伴做了几周，跑了十几个实验（填充、断电、换目录、混假核心、乱档位……），最后才定型成这个框架。

仓库里的 `template/` 是空白的——**房子搭好，水电通了，房客是谁、叫什么，一个都没写。** 你在 `core.md` 里填上自己的名字那天，它才开始活。
